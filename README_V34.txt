V34 – Bestätigung sichtbar machen
Die Meldung zur Adminentscheidung bleibt nun auch beim Scrollen am oberen Bildschirmrand sichtbar, bis Gelesen gedrückt wird. Die neueste Entscheidung pro Versuch wird angezeigt.
Zusätzlich zeigt die Startseite einen dauerhaften Status Aufnahmeprüfung bestanden für das angemeldete Konto, sobald ein bestandener Online-Versuch vorliegt.
Eine vom Admin anerkannte Aufnahmeprüfung befördert Agentenschüler zum Agenten. Mitarbeiter-/Adminrollen bleiben erhalten. Bereits anerkannte, aktuell bestandene Aufnahmeprüfungen wurden entsprechend übernommen.
Nach Hochladen Website auf beiden Geräten neu laden. Bereits gespeicherte Bestätigungen bleiben erhalten.
Geprüft: JavaScript-Syntax, Dateivergleich, Empfängerfilter und Statusdarstellung. Die konkrete vorhandene Anerkennung wurde auf dem Server verifiziert. Kein echter iPhone-Test.
